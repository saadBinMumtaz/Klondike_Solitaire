# Klondike Solitaire

A GUI Solitaire game made for the DSA mid term project.

## Rules
1.Piles of 7 cards from 1 to 7 having cards accordingly 
2.Then make the cards from ace upto king 
3.The making alternate colors should be use for creating stack then we can put after the specific pile later 

## Data structures used
Stack: foundation piles, waste pile, undo and redo history
Queue: stock pile
Linked list: tableau piles
List: the deck of 52 cards
Dictionary: pile names and card locations

## How to run
python main.py

## How to test
python -m pytest
